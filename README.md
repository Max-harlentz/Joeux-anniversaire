# 🎂 Site Web Surprise d'Anniversaire

Un petit projet web interactif conçu avec amour et une bonne dose d'humour pour célébrer un anniversaire inoubliable ! ✨

## 🌟 Fonctionnalités

* 🧩 *Énigme interactive :* Un mot secret à deviner pour débloquer la surprise et accéder au message principal.
* 🎶 *Ambiance musicale :* Un lecteur audio intégré pour accompagner la lecture en musique.
* 💬 *Message personnalisé :* Un texte unique qui célèbre à la fois l'élégance et la douce folie de l'invitée d'honneur.
* 📸 *Galerie souvenir :* Une mise en page soignée pour sublimer les photos et les souvenirs.

## 🛠️ Technologies utilisées

* *HTML5* pour la structure de la page.
* *CSS3* pour le design et le style.
* *JavaScript* pour la logique interactive (vérification de l'énigme et gestion du lecteur audio).
